# Contributing to Contacts Manager App

Thank you for considering contributing to the Contacts Manager App! We appreciate your help in improving this project. Here are some guidelines to help you get started:

## How to Contribute

1. **Fork the Repository**: Start by forking the repository to your own GitHub account.
2. **Clone your Fork**: Clone your forked repository to your local machine.
3. **Create a Branch**: Create a new branch for your feature or bug fix. For example:
   ```bash
   git checkout -b my-feature-branch
   ```
4. **Make Changes**: Implement your changes in your branch.
5. **Test Your Changes**: Ensure your changes work as intended and pass the existing tests.
6. **Commit Your Changes**: Commit your changes with a descriptive commit message. For example:
   ```bash
   git commit -m 'Add new feature'
   ```
7. **Push to GitHub**: Push your changes to your forked repository.
8. **Create a Pull Request**: Navigate to the original repository and create a pull request from your branch.

## Guidelines
- Follow the existing code style and conventions used in the project.
- Write clear and descriptive commit messages.
- If you're adding a new feature, consider adding tests to ensure its functionality.
- Keep your pull request focused on a single issue or feature for easier review.

## Code of Conduct
Please adhere to the [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions relating to this project. We are committed to providing a welcoming environment for all contributors.

## Questions?
If you have any questions, feel free to reach out by opening an issue or contacting the project maintainers directly.

Thank you for contributing!
